Programar con Scratch y comenzar con Python

Durante este trimestre aprenderemos que las ideas de programación son las mismas aunque cambie el lenguaje: primero las veremos de forma visual en Scratch y después comenzaremos a expresarlas con Python. También aplicaremos esa lógica al control de sistemas físicos y robots.

🧠 Algoritmo → 🧩 Scratch → 🐍 Python → 🔀 Decisión → 🔁 Bucle → 🤖 Robótica
01 Algoritmos: antes de programar, pensar
Idea básica: un algoritmo es una secuencia ordenada y precisa de instrucciones. Podemos expresarlo con palabras, con un diagrama, con bloques de Scratch o con código Python.

🧠 Problema sencillo

Queremos que un personaje avance, gire y salude.

  1. Avanzar.
  2. Girar.
  3. Mostrar un saludo.

🧩 En Scratch

al presionar bandera verde
mover 30 pasos
girar ↻ 90 grados
decir ¡Hola! durante 2 segundos
🎯 Reto: escribe primero el algoritmo con palabras y después construye una versión en Scratch.
02 De Scratch a Python: mismo algoritmo, otro lenguaje
Scratch utiliza bloques. Python utiliza instrucciones escritas. La forma cambia, pero la idea del algoritmo sigue siendo la misma.
🧩 Scratch
decir ¡Hola!
🐍 Python
print("¡Hola!")
decir Hola
↔
print("Hola")
fijar puntos a 0
↔
puntos = 0
preguntar ¿Nombre? y esperar
↔
nombre = input("Nombre: ")
03 Variables: la memoria del programa
Una variable guarda un dato que el programa puede utilizar o modificar durante su ejecución.
📦 nombre Guarda texto.
🎂 edad Guarda un número.
⭐ puntos Puede cambiar durante un juego.

🧩 Scratch

fijar puntos a 0
cambiar puntos por 1

🐍 Python

puntos = 0
puntos = puntos + 1

print(puntos)
🎯 Reto: crea una variable edad en Scratch y otra variable edad en Python.
04 Entrada y salida: hablar con el programa
Los programas pueden recibir datos del usuario (entrada) y mostrar un resultado (salida).

🧩 Scratch

preguntar ¿Cómo te llamas? y esperar
decir respuesta

🐍 Python

nombre = input("¿Cómo te llamas? ")

print("Hola", nombre)
Entrada → Procesamiento → Salida
🎯 Reto: pregunta nombre y edad y muestra un saludo personalizado tanto en Scratch como en Python.
05 Condiciones: Scratch decide, Python también
Una condición permite ejecutar una acción solamente cuando una expresión es verdadera.

🧩 Scratch

si <edad ≥ 12> entonces
decir Puedes continuar
si no
decir Todavía no

🐍 Python

if edad >= 12:
    print("Puedes continuar")
else:
    print("Todavía no")

🧮 Operadores de comparación

> Mayor que
< Menor que
== Igual que
🎯 Reto: programa el mismo problema en Scratch y Python: indicar si un número es positivo, negativo o cero.
06 Bucles: repetir sin copiar
Un bucle permite repetir instrucciones automáticamente. Scratch lo representa visualmente; Python utiliza estructuras escritas.

🧩 Scratch · repetir

repetir 5
decir Hola

🐍 Python · for

for i in range(5):
    print("Hola")

🧩 Scratch · por siempre

por siempre
mover 5 pasos

🐍 Python · while

while True:
    print("Repitiendo...")
🎯 Reto: muestra los números del 1 al 10 primero con Scratch y después con Python.
07 Combinar estructuras: pequeño proyecto
Un programa real combina variables, entrada de datos, decisiones y repeticiones.

🎮 Opción Scratch

Crea un quiz de preguntas con una variable puntos.

  • pregunta;
  • comprueba la respuesta;
  • suma puntos;
  • repite varias preguntas.

🐍 Opción Python

puntos = 0

respuesta = input("2 + 2 = ")

if respuesta == "4":
    puntos = puntos + 1

print("Puntos:", puntos)
🚀 Desafío: crea las dos versiones del mismo pequeño programa y explica qué bloques de Scratch corresponden a cada instrucción Python.
08 De Scratch a la robótica
En robótica seguimos utilizando exactamente la misma lógica. La diferencia es que la salida ya no ocurre solo en la pantalla: puede encender un LED, mover un motor o hacer girar un robot.
🎛️ Entrada / sensor → 🧠 Programa → 🔀 Decisión → ⚙️ Actuador

🧩 Lo que ya sabemos

cuando ocurre un evento
si <se cumple condición>
realizar acción

🤖 En un robot

  1. Un sensor recibe información.
  2. El programa comprueba una condición.
  3. El robot toma una decisión.
  4. Un motor, LED u otro actuador responde.
🎯 Ejemplo: si el robot detecta un obstáculo cerca, detenerse y girar.

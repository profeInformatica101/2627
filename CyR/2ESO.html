12 Situaciones de Aprendizaje ·
Computación y Robótica · 2.º ESO

Secuencia propuesta: programación y Scratch → micro:bit e IoT → Maqueen → desarrollo web responsive con HTML, CSS y JavaScript → datos, IA y ciberseguridad.

Progresión: el conocimiento no se reinicia al cambiar de bloque. Los algoritmos, variables, condiciones, operadores y bucles trabajados con Scratch se reutilizan en micro:bit y Maqueen y, posteriormente, en JavaScript. La parte móvil se aborda mediante una única web responsive capaz de adaptarse a móvil, tablet y ordenador.

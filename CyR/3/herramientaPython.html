🐍 Herramientas para aprender Python

Computación y Robótica · 3.º de ESO

Python es un lenguaje de programación con el que aprenderemos a crear algoritmos, resolver problemas y desarrollar nuestros propios programas. Puedes utilizar herramientas instaladas en tu ordenador o programar directamente desde Internet.

💻 1. Programas para instalar en el ordenador

Estas herramientas permiten trabajar con Python desde el equipo. Algunas requieren instalar Python por separado.

⭐ Thonny — Recomendado para empezar

Entorno sencillo para escribir, ejecutar y depurar programas Python paso a paso.

⬇ Descargar Thonny

Mu Editor

Editor de Python diseñado para principiantes, con una interfaz clara y fácil de utilizar.

⬇ Descargar Mu Editor

IDLE — Editor oficial de Python

Editor básico que normalmente se incluye al instalar Python desde su página oficial.

⬇ Descargar Python e IDLE

Visual Studio Code

Editor avanzado que permite programar en Python mediante extensiones. Recomendado cuando ya domines los fundamentos.

⬇ Descargar VS Code

PyCharm

Entorno de desarrollo para crear proyectos Python más completos. Dispone de funcionalidades gratuitas.

⬇ Descargar PyCharm

🌐 2. Herramientas online — Sin instalación

Estas páginas permiten programar directamente desde el navegador. Son especialmente útiles para practicar desde casa o desde cualquier ordenador.

⭐ Programiz — Editor Python online

Escribe y ejecuta programas Python directamente desde Internet. Muy recomendable para nuestros primeros ejercicios.

▶ Abrir Programiz

⭐ Python Tutor — Visualizador de algoritmos

Permite ejecutar programas paso a paso y observar cómo cambian las variables. Ideal para comprender condiciones, bucles y listas.

▶ Abrir Python Tutor

Trinket — Python interactivo

Permite crear, ejecutar y compartir programas desde el navegador. También ofrece opciones para insertar actividades en páginas educativas.

▶ Abrir Trinket

Google Colab

Cuadernos interactivos donde puedes combinar explicaciones, código Python y resultados. Puede requerir una cuenta de Google.

▶ Abrir Google Colab

Replit

Plataforma online para crear proyectos de programación. Algunas funciones requieren una cuenta o un plan de pago.

▶ Abrir Replit

OnlineGDB

Editor y depurador online que permite ejecutar programas Python y practicar la localización de errores.

▶ Abrir OnlineGDB

W3Schools Python

Incluye explicaciones, ejemplos y ejercicios interactivos para aprender la sintaxis de Python.

▶ Aprender Python en W3Schools

🎯 ¿Por dónde empezar?

1. Utiliza Programiz para escribir y ejecutar tus primeros programas.

2. Abre Python Tutor para comprender cómo se ejecutan las instrucciones.

3. Si quieres programar sin conexión a Internet, instala Thonny.

4. Cuando tengas más experiencia, prueba VS Code o PyCharm.

🚀 Tu primer reto en Python

Abre Programiz y escribe este programa:

nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))

print("Hola,", nombre)

if edad >= 14:
    print("Tienes 14 años o más.")
else:
    print("Tienes menos de 14 años.")

Actividades: ejecuta el programa, modifica los mensajes, prueba distintas edades y explica qué función cumple la instrucción if.

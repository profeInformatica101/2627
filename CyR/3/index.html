01Algoritmos: pensar antes de programar

Un algoritmo es una secuencia finita y ordenada de instrucciones para resolver un problema. Debemos distinguir los datos de entrada, las operaciones y el resultado.

Problema: calcular el doble de un número
Leer número→Multiplicar × 2→Mostrar resultado
PYTHON · Ejemplo 01 
numero = int(input("Escribe un número: "))
doble = numero * 2
print("El doble es:", doble)
Prueba: si introduces 7, debe aparecer El doble es: 14. ¿Qué ocurre si introduces 0 o -3?

03Variables, tipos y operadores

Una variable permite guardar un valor. Python diferencia, entre otros, enteros (int), decimales (float), textos (str) y booleanos (bool).

PYTHON · Ejemplo 03 
nombre = "Ana"        # str: texto
edad = 14            # int: entero
altura = 1.62        # float: decimal
activo = True        # bool: verdadero/falso

puntos = 10
puntos = puntos + 5
print(nombre, "tiene", puntos, "puntos")

04Entrada y salida de información

input() recoge lo que escribe el usuario, pero siempre devuelve texto. Para calcular con números, convierte ese texto con int() o float().

PYTHON · Ejemplo 04 
nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Qué edad tienes? "))
print("Hola,", nombre)
print("El próximo año tendrás", edad + 1)
Observa: "3" + "2" produce "32" (texto), mientras que 3 + 2 produce 5 (números).

05Condicionales: el programa decide

Con if, elif y else hacemos que el programa elija qué instrucciones ejecutar según una condición.

PYTHON · Ejemplo 05 
numero = int(input("Introduce un número: "))

if numero > 0:
    print("Positivo")
elif numero < 0:
    print("Negativo")
else:
    print("Cero")
Comparaciones

>, <, >=, <=, ==, !=.

Reglas de escritura

Después de la condición se escriben : y las instrucciones interiores van sangradas.

Importante: = asigna un valor; == compara si dos valores son iguales.

06Bucles: repetir sin copiar instrucciones

for es útil cuando sabemos cuántas veces repetiremos algo. while repite mientras una condición sea verdadera.

Bucle for

PYTHON · Ejemplo 06A 
for n in range(1, 6):
    print(n)

Muestra 1, 2, 3, 4 y 5. El límite superior no se incluye.

Bucle while

PYTHON · Ejemplo 06B 
contador = 3
while contador > 0:
    print(contador)
    contador -= 1
print("¡Despegue!")

La variable cambia para que el bucle pueda terminar.

07Funciones: organizar y reutilizar código

Una función agrupa instrucciones para resolver una tarea. Puede recibir parámetros y devolver un resultado mediante return.

PYTHON · Ejemplo 07 
def calcular_area(base, altura):
    return base * altura / 2

area = calcular_area(8, 5)
print("Área del triángulo:", area)
Reto: crea una función calcular_doble(numero) que devuelva el doble de cualquier número.

08Aplicación: un robot que toma decisiones

Un robot utiliza sensores para captar información, un programa para procesarla y actuadores para responder. Podemos simular su comportamiento con Python sin disponer de un robot físico.

Sensor de distancia→Condición→Motor / acción
PYTHON · Ejemplo 08 
distancia = float(input("Distancia al obstáculo (cm): "))

if distancia < 20:
    print("Robot: DETENERSE")
else:
    print("Robot: AVANZAR")
Prueba: ¿qué sucede con 10, 20 y 50 cm? Modifica la distancia de seguridad a 30 cm.

¿Por qué mi programa muestra un error?

Comprueba las comillas, los paréntesis, los dos puntos al final de if y for, la sangría y los nombres de variables. Lee el mensaje de error y revisa la línea indicada.

¿Por qué input() no suma números?

Porque devuelve texto. Convierte la entrada con int(input(...)) o float(input(...)) cuando necesites calcular.

¿Puedo avanzar si no entiendo un ejercicio?

Vuelve al ejemplo anterior, cambia un dato, predice el resultado y ejecútalo. Anota exactamente dónde aparece la duda para consultarla en clase.

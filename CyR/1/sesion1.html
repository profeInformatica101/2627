Palabra 1 de 5

Un algoritmo es un plan

Es una serie de pasos ordenados para conseguir un objetivo. Se puede explicar con palabras o dibujos antes de abrir Scratch.

Algoritmo = pasos ordenados para resolver un problema.

Ejemplo: preparar un bocadillo

1. Coger pan.2. Abrir el pan.3. Poner el relleno.4. Cerrar el pan.

Si cambias el orden, quizá no obtengas el mismo resultado.

Palabra 2 de 5

Del algoritmo al programa

Un programa expresa las instrucciones de manera que el ordenador pueda ejecutarlas. En Scratch escribimos ese plan uniendo bloques.

Algoritmo = lo que planeo. Programa = instrucciones que ejecuta el ordenador.

Palabra 3 de 5

La variable guarda un dato

Imagina una caja con una etiqueta. La etiqueta es el nombre de la variable; dentro guardamos un valor que puede cambiar.

Variable = nombre + valor guardado. Ejemplo: apodo = «Pixel».

Preguntar, guardar y usar

Scratch tiene un bloque respuesta, que guarda temporalmente la última contestación. Si vas a preguntar otra cosa, copia antes esa respuesta en una variable.

Control 1 de 3

Secuencia: una cosa después de otra

Las instrucciones se ejecutan en un orden. Si intentas usar la variable antes de guardar la respuesta, el saludo no funcionará como esperas.

Secuencia = primero → después → al final.

¿Cuál es el orden correcto?

1. Preguntar un apodo.2. Guardar «respuesta» en «apodo».3. Decir «Hola» y mostrar «apodo».

Pregunta en voz alta: ¿qué pasaría si intercambiamos los pasos 2 y 3?

Control 2 de 3

Condición: elegir un camino

El programa comprueba si algo es verdadero. Si se cumple, ejecuta un grupo de instrucciones; si no, ejecuta otro.

Si ocurre esto → hago A. Si no → hago B.

Control 3 de 3

Repetición: hacer algo varias veces

En lugar de colocar tres veces el mismo bloque, indicamos cuántas veces se debe ejecutar.

Repetir 3 = ejecutar las instrucciones de dentro tres veces.

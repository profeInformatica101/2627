¿Cómo damos instrucciones a un ordenador?

Un ordenador no adivina lo que queremos. Necesita instrucciones claras, ordenadas y sin pasos escondidos.

1 · Secuencia

Hacer pasos uno detrás de otro.

A→B→C

2 · Decisión

Elegir un camino según una condición.

¿Se cumple?SÍ →
NO →

3 · Repetición

Volver a hacer una acción un número de veces.

PASO 02/11 5–11 min

Las piezas de un diagrama de flujo

Cada figura tiene un significado. No elegimos la forma por decoración: la forma explica qué tipo de paso estamos realizando.

INICIO / FIN
Óvalo

Marca dónde comienza o termina el algoritmo.

ACCIÓN
Rectángulo

Indica una operación: calcular, guardar o mostrar.

ENTRADA
Paralelogramo

Sirve para introducir o mostrar información.

¿PREGUNTA?
Rombo

Plantea una condición con salidas Sí y No.

→
Flecha

Indica el orden y la dirección de los pasos.

1Empieza en INICIO y sigue siempre las flechas. 2Dentro de cada figura escribe una instrucción breve y concreta. 3En cada rombo rotula las dos salidas: Sí y No. 4Comprueba que todos los caminos llegan a otro paso o a FIN.

PASO 03/11 11–16 min

Antes del código: el algoritmo

Un algoritmo es una lista ordenada de pasos para resolver una tarea.

Algoritmo en lenguaje cotidiano

  1. Mostrar un saludo.
  2. Preguntar el nombre.
  3. Guardar la respuesta.
  4. Mostrar el nombre.

Esto todavía no es Python. Es la idea antes de programar.

Lee de arriba abajo: cada flecha conduce al paso siguiente.

PASO 05/11 21–27 min

Estructura 1 · Secuencia

En una secuencia, Python ejecuta las instrucciones de arriba hacia abajo.

print("Ayudante de clase")
nombre = input("¿Cómo te llamas? ")
print("Hola", nombre)

Diagrama ↔ código

Mostrar → print()

Preguntar → input()

Guardar → una variable como nombre

PASO 06/11 27–34 min

Estructura 2 · Decisión con if

Solo se recorre una rama. Después, ambos caminos llegan a FIN.

respuesta = input("¿Sobra una luz? (si/no) ")

if respuesta == "si":
    print("Apágala")
else:
    print("Gracias")
Idea clave: el rombo del diagrama se convierte en una pregunta en Python. if significa “si ocurre esto…”.

Predice: ¿qué línea se ejecuta si escribimos no?

PASO 07/11 34–40 min

Estructura 3 · Repetición con for

for vez in range(3):
    print("Revisar las luces")

¿Qué significa?

range(3) hace que el bloque se repita 3 veces.

Las líneas con sangría pertenecen al for.

Prueba mental: cuenta con los dedos cuántas veces aparecerá “Revisar las luces”.

1 → 2 → 3 → FIN. Tras cada vuelta, el contador aumenta y se comprueba de nuevo.

PASO 09/11 45–51 min

Construimos el programa completo

Ahora unimos secuencia + repetición + decisión.

print("Ayudante para ahorrar luz")

nombre = input("¿Cómo te llamas? ")
print("Hola", nombre)

for ronda in range(1, 4):
    print("Ronda", ronda)
    respuesta = input("¿Sobra alguna luz encendida? (si/no) ")

    if respuesta == "si":
        print("Apaga la luz que no necesites")
    else:
        print("Gracias por comprobarlo")

print("Hasta luego", nombre)

Secuencia

Saludar, preguntar y despedirse.

Repetición

El for hace 3 rondas.

Decisión

El if elige un mensaje.

PASO 10/11 51–54 min

¿Algo falla? Aprende a depurar

1 · Falta :

if respuesta == "si":

Los dos puntos son obligatorios.

2 · Sangría

if respuesta == "si":
    print("Apágala")

Las instrucciones interiores deben estar desplazadas.

3 · = y ==

= guarda un valor.

== compara dos valores.

Mini reto: cambia el programa para repetir 5 veces. No cambies nada más.

PASO 02/09 4–10 min

Primero, un algoritmo

Un algoritmo es una serie ordenada de instrucciones que permite resolver una tarea.

En parejas: robot y programador

  1. Una persona hace de robot: solo cumple instrucciones literales.
  2. La otra le dice cómo saludar, preguntar y responder.
  3. Intercambiad papeles. ¿Qué paso faltaba?

En tu libreta

PASO 04/09 16–22 min

Estructura 1: secuencia

print("Ayudante para ahorrar luz")
nombre = input("¿Cómo te llamas? ")
print("Hola,", nombre)

Lee de arriba abajo

print() muestra texto. input() recibe una respuesta. nombre es una variable donde guardamos esa respuesta.

Si escribes «Ana», ¿qué mostrará la última línea?

Libreta: añade «mostrar saludo» y «preguntar nombre» a tu diagrama. Escribe qué guarda nombre.

PASO 05/09 22–28 min

Estructura 2: decisión

respuesta = input("¿Sobra una luz? (si/no) ")
if respuesta == "si":
    print("Apágala")
else:
    print("Gracias por comprobarlo")

Dos rutas: solo una se cumple

if comprueba la respuesta. else indica qué hacer en los demás casos.

¿Qué mostrará al escribir no?

Libreta: dibuja un rombo «¿respuesta = si?». Traza dos flechas llamadas «sí» y «no» con sus mensajes.

PASO 06/09 28–34 min

Estructura 3: repetición

for ronda in range(1, 4):
    print("Ronda", ronda)
    print("¿Sobra una luz?")

Tres rondas

range(1, 4) produce 1, 2 y 3. El 4 no está incluido. Las líneas sangradas se repiten.

¿Cuántas veces aparece la pregunta?

Libreta: añade una flecha que regrese a «preguntar» y otra que salga cuando terminen las tres rondas.

PASO 08/09 40–52 min

Lo escribimos en Python

Guarda sesion1.py. Puedes copiar el código para dedicar tiempo a comprenderlo y probarlo. Responde si, no, si sin tilde.

print("Ayudante para ahorrar luz")
nombre = input("¿Cómo te llamas? ")

for ronda in range(1, 4):
    print("Ronda", ronda)
    respuesta = input("¿Sobra alguna luz encendida? (si/no) ")

    if respuesta == "si":
        print("Apaga la luz que no necesites,", nombre)
    else:
        print("Gracias por comprobarlo,", nombre)

print("Hasta luego,", nombre)
¿Hay un error? Abre esta ayuda
  • IndentationError: conserva los espacios antes de cada línea del for y de las dos ramas.
  • SyntaxError: revisa comillas y dos puntos :.
  • Mensaje inesperado: escribe si en minúsculas y sin tilde.

Sin ordenadores: ejecuta el código con tu pareja, siguiendo línea por línea el diagrama y registrando los mensajes.

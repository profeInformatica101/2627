Problemas básicos con slider interactivo

Esta web presenta problemas sencillos para trabajar estructuras secuenciales, condicionales y repetitivas. En cada tarjeta aparece el enunciado, el algoritmo, una propuesta de diagrama de flujo y una idea de implementación con Scratch.

El objetivo es que el alumnado entienda que primero se piensa la solución, después se ordena en pasos y, por último, se lleva a un programa.

📦 Entrega Moodle

El alumnado debe entregar:
  • Diagramas de flujo de los problemas trabajados.
  • Explicación breve de dos algoritmos con sus pasos.
  • Implementación con Scratch de los problemas seleccionados.
Sugerencia didáctica: puedes pedir que cada pareja elija 2 problemas, explique el algoritmo con sus propias palabras y adjunte una captura del proyecto Scratch.

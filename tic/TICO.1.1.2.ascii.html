¿Cómo representa el ordenador las letras?

TIC · 1.º Bachillerato · Representación de la información · Tema 2

El problema

Un ordenador trabaja con bits (0 y 1), pero nosotros escribimos letras, números, signos de puntuación y símbolos.

Necesitamos una tabla de correspondencias que asigne un número a cada carácter. Una de las primeras normas ampliamente utilizadas fue ASCII.

Carácter

Lo que vemos y escribimos: A, ?, 7.

Código

Un número asociado al carácter, por ejemplo, A = 65.

Binario

Ese número puede almacenarse como bits: 01000001.

En esta unidad veremos cómo pasar de carácter a decimal y de decimal a binario.

1. ¿Qué es ASCII?

ASCII significa *American Standard Code for Information Interchange* (Código Estándar Estadounidense para el Intercambio de Información).

La idea fundamental

ASCII asigna un número a cada carácter. El ASCII estándar utiliza 7 bits, por lo que permite representar:

2⁷ = 128 códigos (0–127)

Caracteres de control

Códigos 0–31 y 127. Se crearon para controlar dispositivos y comunicaciones; muchos no se muestran como símbolos.

Caracteres imprimibles

Códigos 32–126: espacio, signos de puntuación, cifras, letras y algunos símbolos.

Importante: ASCII estándar no incluye directamente letras como ñ ni vocales acentuadas.

2. ¿Cómo se almacena un carácter?

El código ASCII de un carácter es un número. Después, ese número se representa en binario.

Ejemplo: la letra A

Carácter

A

Decimal

65

Binario (7 bits)

1000001

Si se muestra en un byte de 8 bits, se añade un cero a la izquierda:

01000001

Otro ejemplo: a minúscula = 97 = 01100001. Las mayúsculas y minúsculas tienen códigos diferentes.

Una regularidad útil

Las letras mayúsculas A–Z ocupan los códigos 65–90 y las minúsculas a–z los códigos 97–122.

La diferencia entre una letra minúscula y su correspondiente mayúscula es 32. Por ejemplo: a = 97 y A = 65.

5. De carácter a decimal y binario

Método: busca el carácter en la tabla ASCII, localiza su número decimal y convierte ese número a binario.

Ejemplo: carácter C

1. En la tabla ASCII, C corresponde al decimal 67.

2. Descomponemos 67 en potencias de 2: 64 + 2 + 1.

3. Marcamos los pesos 64, 2 y 1:

67 = 01000011

Por tanto: C → 67 → 01000011 (en 8 bits).

Otro ejemplo: el carácter 0

0 (carácter) = 48 (decimal) = 00110000 (binario).

Recuerda: el carácter «0» no tiene el mismo código que el número cero usado en una operación.

6. De decimal a carácter

El proceso inverso consiste en consultar qué carácter corresponde a un código decimal.

Ejemplo 1

El código decimal 66 corresponde a la letra B.

Ejemplo 2

El código decimal 63 corresponde al signo ?.

Atención: los códigos 0–31 y 127 son controles, no caracteres imprimibles normales. No todos producen un símbolo visible.

Si recibes una secuencia de códigos, debes separar cada código y buscar su carácter correspondiente.

7. Codificar una palabra

Para codificar una palabra, sustituimos cada carácter por su código ASCII. Cada carácter se representa por separado.

Ejemplo: SOL

CarácterSOL
Decimal837976
Binario (8 bits)010100110100111101001100

La palabra SOL se representa como tres códigos consecutivos: 83, 79 y 76.

Para recuperar el texto, agrupamos los bits en bytes, convertimos cada byte a decimal y consultamos la tabla.

8. ASCII y Unicode: ¿son lo mismo?

ASCII

  • Estándar de 7 bits.
  • 128 códigos.
  • Incluye letras inglesas básicas, cifras y signos.
  • No incluye directamente ñ ni vocales acentuadas.

Unicode

  • Estándar para representar caracteres de muchos idiomas y sistemas de escritura.
  • Incluye caracteres como ñ, á, €, y muchos otros.
  • UTF-8 es una forma habitual de codificar Unicode.
Relación: los primeros 128 códigos de Unicode coinciden con ASCII. UTF-8 representa esos caracteres con los mismos valores de un byte.

Por eso, al trabajar con textos actuales en español, normalmente encontramos Unicode/UTF-8 y no solo ASCII.

13. Reto final: descifra el mensaje

Un mensaje se ha almacenado usando códigos ASCII decimales:

72 – 79 – 76 – 65

  1. Busca cada número en la tabla ASCII.
  2. Escribe el carácter que corresponde a cada código.
  3. ¿Qué palabra se forma?
  4. Convierte el código decimal 72 a binario de 8 bits.
Solución razonada

72 = H, 79 = O, 76 = L y 65 = A. El mensaje es HOLA. El código 72 en binario de 8 bits es 01001000.
